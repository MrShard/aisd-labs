# Алгоритмы и структуры данных — лабораторные работы

Язык: Python 3. Каждая задача лежит в отдельном файле.

## Как запустить

```bash
python lab01/task01_rectangle.py
```

Программа спросит входные данные. Массивы вводятся одной строкой через пробел, матрицы — построчно.
В лабах 7–11 можно просто нажать Enter, тогда возьмётся пример.
