# Алгоритмы и структуры данных — лабораторные работы

Язык — Python 3. У каждой задачи есть отдельный файл, а в файле `labXX.py` собраны все задачи соответствующей лабораторной.

## Как запустить

В VS Code откройте, например, `lab01/lab01.py` и выберите **Run Python File in Terminal**. Из корня репозитория этот же файл запускается командой `python lab01/lab01.py`.

- В ЛР 1–6 введите номер задачи. Затем Enter подставит пример, а `1` включит ручной ввод. Если в меню вместо номера нажать Enter или ввести `0`, все примеры выполнятся подряд.
- В ЛР 7–11 Enter сразу запустит пример, а `1` включит ручной ввод.
- В ЛР 12 Enter запустит демонстрацию очередей.

Отдельную задачу можно запустить командой `python lab01/task01_rectangle.py`. При ручном вводе числа массива вводятся через пробел, матрицы вводятся построчно.
